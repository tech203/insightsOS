Setup instructions

  1. Go to Webflow API Settings and create or copy an API token.
  2. Find your Site ID and Collection IDs in your Webflow site settings.
  3. Add the following to your .env file:
    WEBFLOW_API_TOKEN=your_token_here WEBFLOW_SITE_ID=your_site_id WEBFLOW_BLOG_COLLECTION_ID=your_blog_id WEBFLOW_FAQ_COLLECTION_ID=your_faq_id WEBFLOW_SERVICE_COLLECTION_ID=your_service_id WEBFLOW_LOCATION_COLLECTION_ID=your_location_id WEBFLOW_PUBLISH_ON_EXPORT=false
  4. Restart the server. This page will show your live collections once it can authenticate.

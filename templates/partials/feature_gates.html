{# Feature-gate macros. Replaces the legacy pattern where every gated button looked live to Free users (whole UI clickable), then redirected to /pricing on click. Now we render disabled-with-Pro-badge so the user knows at a glance what's available on their plan and can decide whether to upgrade before they invest energy in a flow. Usage in templates: {% from "partials/feature_gates.html" import pro_badge, locked_nav_item, locked_link, gated_button %} All macros use `feature_gates` from the global template context (set in inject_template_globals in app.py). Callers pass the gate key as a string: "gsc", "competitors", "multi_engine", "workspace_addon", "seat_addon", or "white_label". #} {# Small "Pro" pill rendered inline next to a feature name. Kept visually small so it doesn't fight with the surrounding label. #} {% macro pro_badge(label="Pro") %} {{ label }} {% endmacro %} {# Sidebar nav item that becomes a non-clickable element with a Pro pill + tooltip when the user's plan doesn't include the feature. Args: gate_key — string key in feature_gates (e.g. "gsc") url — destination URL when unlocked endpoint — Flask endpoint name for active-state check label — visible link text icon — name of the sprite icon to render via {{ nav_icon(icon) }} tooltip — fallback tooltip text (defaults to label) #} {% macro locked_nav_item(gate_key, url, endpoint, label, icon, tooltip=None, current_endpoint=None) %} {% set tooltip = tooltip or label %} {% if feature_gates and feature_gates[gate_key] %} {{ nav_icon(icon) }} {{ label }} {{ tooltip }} {% else %} {# Locked: render as a non-link with a Pro badge + "Upgrade to use" tooltip + a click that opens the pricing page. Using with a click-through to /pricing keeps keyboard / screen-reader access — disabled {% else %} {{ button_label }} {{ pro_badge() }} {% endif %} {% endmacro %}
